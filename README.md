# ExpenseTracker(Java)

# Project Description
This is a simple Java-based Expense Tracker Application which allows users to add and manage expenses.It is a menu-driven console program created as part of the Java flipped course project.

 # Features
 - Add new Expenses
 - View all Expenses
 - View total Expenses
 - Filter expenses by category

# Technologies Used
- Java (Core Java)
- OOP Concepts
- ArrayList

# Project Structure
src/
  ├── Expense.java
  ├── ExpenseManager.java
  └── Main.java
screenshots

# How to Run the Project
1. Open project in any Java IDE (VS Code / IntelliJ / Eclipse)
2. Compile all files
3. Run Main.java
4. Use the menu to interact with the program

# Sample Menu
1. Add Expense
2. Show All Expenses
3. Show Total Expenses
4. Show By Category
5. Exit
